# Stellar Burgers — Redux

Работа выполнена на основе официального стартового архива Яндекс Практикума
`stellar-burgers-main (2).zip`. Сохранены его компоненты, стили, зависимости
и lock-файл. Добавлены Redux, роутинг, авторизация, конструктор и заказы.

## Как запустить на другом компьютере

1. Установите Node.js. Проект проверен на Node.js 22.22.0 и npm 10.9.4.
2. Распакуйте ZIP в **новую папку**. Не смешивайте его со старой копией проекта.
3. Откройте терминал в папке, где находится `package.json`, и выполните:

```sh
npm ci
npm start
```

Откройте [localhost:4000](http://localhost:4000).
Если старая версия уже запущена на этом порту, сначала остановите её через
Ctrl+C в её терминале.

## Подключение к API

Файл `.env` уже включён в ZIP и содержит только публичный адрес учебного API:

```dotenv
BURGER_API_URL=https://norma.education-services.ru/api
```

Отдельный сервер на `localhost:3001` не нужен. Если `.env` отсутствует,
сборщик автоматически использует `.env.example`. Если вы изменили `.env`,
остановите `npm start` и запустите его снова.

Для загрузки ингредиентов и работы с аккаунтом нужен доступ к интернету.
Если ингредиенты не загружаются, проверьте, открывается ли
[учебный API](https://norma.education-services.ru/api/ingredients)
в том же браузере. Ошибка `ERR_CONNECTION_REFUSED` с адресом `localhost:3001`
означает, что запущена другая сборка или использованы старые настройки.

## Что реализовано

- Загрузка ингредиентов, счётчики, замена булки, добавление, удаление и
  перестановка начинок, подсчёт стоимости.
- Регистрация, вход, выход, восстановление пароля, редактирование профиля,
  обновление токена, защита личных страниц и возврат после входа.
- Оформление заказа с очисткой конструктора после успешного ответа.
- Лента, история, статусы, состав и стоимость заказов. Списки обновляются
  после оформления и каждые 5 секунд, пока соответствующая страница открыта.
- Модальные окна ингредиентов и заказов; отдельные страницы при прямом
  переходе по URL; обработка неизвестных адресов и ошибок загрузки.

## Проверки

```sh
npm run typecheck
npm run lint
npm test
npm run test:coverage
npm run build
```

Проверены чистая установка через `npm ci`, TypeScript, ESLint и сборка.
54 теста приложения и 2 теста настоящей webpack-сборки проходят.
Тест настройки подтверждает правильный адрес API даже без `.env`.
Покрытие строк сервисов и API — около 98%, ветвей — около 87%.
Webpack сообщает только рекомендации по размеру основного JavaScript-файла.

Браузерный сценарий с изолированными тестовыми ответами находится в
`tests/e2e`. Для его повторения при запущенном приложении:

```sh
npx --yes --package @playwright/cli playwright-cli -s=stellar-check open about:blank
npx --yes --package @playwright/cli playwright-cli -s=stellar-check run-code --filename tests/e2e/seed.js
npx --yes --package @playwright/cli playwright-cli -s=stellar-check run-code --filename tests/e2e/scenario.js
npx --yes --package @playwright/cli playwright-cli -s=stellar-check close
```

Тестовые ответы используются только в этом отдельном браузерном сеансе.
Обычный `npm start` обращается к учебному API.

На машине подготовки 9 сентября 2026 года браузер подтвердил запрос к
`https://norma.education-services.ru/api/ingredients`, но сервер отвечал
тайм-аутом. Поэтому получение живых данных с этой машины не подтверждено.
Реальные пользователи и заказы во время проверки не создавались.
